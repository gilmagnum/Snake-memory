# 🐍 שביל הנחש — משחק זיכרון

משחק זיכרון דפדפני, קובץ HTML יחיד (בלי תלויות, בלי שרת) — גוררים רצף בין משבצות ומנסים לשחזר תבנית שהוצגה לזמן קצוב.

## איך משחקים
- כל שלב מציג רשת משבצות עם תבנית: קו בין מרכזי המשבצות ועיגול בכל אחד משני הקצוות.
- התבנית מוצגת ל-5 שניות ונעלמת.
- משחזרים אותה בגרירה (עכבר או מגע) על המשבצות, בכל אחד משני הכיוונים.
- טעות מורידה חיים אחד, אבל לא מחליפה את התבנית — מנסים שוב עד הצלחה או עד שנגמרים החיים.
- הצלחה מקדמת לשלב הבא (רשת גדולה יותר / נחש ארוך יותר) ומחזירה חיים אחד.
- כשנגמרים כל החיים, התבנית שלא הצלחתם לשחזר מוצגת שוב באפור.

## תכונות
- בלי ספריות חיצוניות — HTML/CSS/JS טהור בקובץ אחד.
- צלילים נבנים בזמן אמת (Web Audio API), כולל כפתור השתקה.
- רשת רספונסיבית שמתאימה את גודל המשבצות לרוחב המסך.
- ממשק RTL מלא בעברית.

## הרצה מקומית
פשוט פותחים את `index.html` בכל דפדפן — אין צורך בהתקנה או שרת.

## פרסום עם GitHub Pages
1. יוצרים ריפו חדש ב-GitHub ומעלים אליו את `index.html` ואת `README.md` (חשוב: הקובץ הראשי חייב להיקרא בדיוק `index.html` כדי שהוא ייטען אוטומטית מהכתובת הראשית).
2. בריפו: **Settings** ← בתפריט הצד **Pages**.
3. תחת **Build and deployment → Source** בוחרים **Deploy from a branch**, ואז **Branch**: `main` (או `master`), תיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי דקה-שתיים, **הלינק הציבורי מופיע באותו עמוד Settings → Pages**, למעלה בתיבה ירוקה שכתוב בה "Your site is live at" — הכתובת תהיה בפורמט:
   ```
   https://<שם-המשתמש-שלך>.github.io/<שם-הריפו>/
   ```
5. כל פעם שדוחפים (`push`) שינוי ל-branch שנבחר, האתר מתעדכן אוטומטית תוך דקה-שתיים.
